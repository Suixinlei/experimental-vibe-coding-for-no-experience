# Tech Debt Tracker

> 集中登记已知技术债。每一条都要能被"还"（有明确的还款路径）。
> 由 agent 定期扫描更新；人类在评审中发现新的债务也要登记。

## 格式

每条债务：

```
### [TD-NNN] <一句话标题>
- 发现于: YYYY-MM-DD
- 位置: <路径 / 域>
- 影响: <阻塞了什么，增加了多少成本>
- 建议方案: <一句话>
- 预估工作量: S / M / L
- 状态: open / in-progress (→ PR#xxx) / closed (→ PR#xxx)
```
