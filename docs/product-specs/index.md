## 模板要素（新建 spec 时参考）

每份 product spec 应包含：

1. **用户是谁** —— 具体到角色与场景，不要"所有人"
2. **问题陈述** —— 他们今天怎么解决，为什么不够好
3. **成功指标** —— 这个功能上线后怎么知道成功了
4. **范围** —— 明确做什么 / 不做什么
5. **用户故事** —— 关键路径的 happy path 与 edge case
6. **开放问题** —— 需要 PM / 设计 / 工程进一步对齐的点
